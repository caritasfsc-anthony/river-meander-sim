# 河曲實驗室 River Meander Lab

🌊 **網上版：** https://caritasfsc-anthony.github.io/river-meander-sim/

一個給中學地理課用的互動河曲模擬。學生在**俯視圖**上用滑鼠或手指畫出河道，再調校**流量**和**流速**，觀察河曲如何隨時間演變：

- **外彎侵蝕**：主流衝向外彎，河岸後退（紅色標示）
- **內彎沉積**：內彎水流較慢，形成曲流沙洲／點沙壩（沙色）
- **河曲遷移**：河曲越來越彎，並向下游移動
- **截彎取直 → 牛軛湖**：曲流頸被沖穿，舊彎道變成牛軛湖，之後慢慢淤積

![截圖](screenshot.png)

## 使用方法

1. 按「✏️ 畫河道」，在地圖上由**上游畫到下游**（或按「🌊 示範河道」）
2. 調校 **流量**（m³/s，河道闊度會隨流量增加）和 **流速**（m/s）
3. 按「▶ 開始」，用「時間速度」控制每秒模擬多少年
4. 「↺ 重設」回到第 0 年；「🧹 清除」重新畫過

支援電腦、平板及手機（觸控）。

## 課堂建議

- 比較不同流量／流速下，第一個牛軛湖在第幾年出現
- 觀察白色水流粒子：外彎較快、內彎較慢
- 留意「舊河道痕跡」如何形成一條河曲帶（meander belt）

## 模型說明

採用簡化的中心線遷移模型（參考 Howard & Knutson, 1984）：河道中心線每一點按「局部曲率＋上游滯後曲率」向外彎方向移動，移動速率隨流速及流量增加；當兩段非相鄰河道距離小於河寬時，便會截彎取直並形成牛軛湖。地圖邊緣代表較難侵蝕的谷壁。此模擬只作教學示意，數值並非精確預測。

## 技術

純 HTML / CSS / JavaScript（Canvas 2D），不需任何建置步驟。`sim.js` 為模擬核心，`app.js` 為介面及繪圖。執行 `node test/sim.test.js` 可測試模擬核心。
